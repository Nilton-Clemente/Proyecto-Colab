# Web de usuario (React)

Aplicación web para los estudiantes (cliente del área de Usuario, paralelo a la app móvil).

- **Responsable:** Persona 3
- **Tecnología:** React (Vite) consumiendo la API de `backend-usuario` (Spring Boot).

## Puesta en marcha

1. Crear el proyecto con [Vite](https://vitejs.dev/) dentro de esta carpeta.
2. Consumir la API de `backend-usuario` mediante el contrato OpenAPI.

## Responsabilidades principales

Mismas funcionalidades de usuario que la app móvil, en web.

Ver acuerdos en el [README raíz](../README.md).
