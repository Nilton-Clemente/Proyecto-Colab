# Proyecto Colab — Documentación

> **Colab** es una aplicación **móvil y web** orientada a facilitar la planificación y organización de proyectos académicos de software. Utiliza inteligencia artificial para analizar la información del proyecto y las habilidades de sus integrantes, con el objetivo de generar una propuesta de planificación personalizada.
