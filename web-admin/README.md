# Web de Administración (React)

Frontend de la plataforma de administración.

- **Responsable:** Persona 3
- **Tecnología:** React (Vite) consumiendo la API de `backend-admin` (Django).

## Puesta en marcha

1. Crear el proyecto con [Vite](https://vitejs.dev/) dentro de esta carpeta.
2. Consumir la API de `backend-admin`.
